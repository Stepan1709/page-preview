\# @step1709/page-preview



Веб-компонент `<page-preview>`: получает URL HTML-страницы, загружает её через `fetch`, извлекает название документа (`title`) и первый заголовок `h1` и показывает компактную карточку со ссылкой.



\## Установка



```

npm install @step1709/page-preview

```



\## Использование



Корневой импорт сам регистрирует элемент, дополнительных вызовов не нужно:



```js

import '@step1709/page-preview';

```



```html

<page-preview src="/pages/example.html"></page-preview>

```



Импорт по имени пакета работает в сборщике (Vite, webpack и т. п.) или через import map:



```html

<script type="importmap">

&#x20; { "imports": { "@step1709/page-preview": "./node\_modules/@step1709/page-preview/src/page-preview.js" } }

</script>

<script type="module">

&#x20; import '@step1709/page-preview';

</script>

```



\## Атрибуты



| Атрибут | Описание |

|---------|----------|

| `src`   | URL HTML-документа. Относительный URL разрешается относительно адреса страницы с компонентом. |



При изменении `src` компонент загружает новую страницу, устаревший ответ не перезаписывает новый.



\## Состояния



Атрибут `data-status` на самом элементе:



\- `loading` — идёт загрузка;

\- `ready` — данные загружены и показаны;

\- `error` — HTTP-ошибка, сетевая ошибка или отсутствует `src`.



\## Shadow DOM и части (`part`)



Shadow DOM открытый. Внутри доступны:



\- `<a part="link">` — ссылка на страницу, текст — название документа либо URL;

\- `<span part="title">` — `document.title.trim()` или «Название отсутствует»;

\- `<span part="heading">` — текст первого `h1` или «Заголовок отсутствует»;

\- `part="message"` — текст сообщения об ошибке.



\## Безопасность



Название и заголовок выводятся только через `textContent`. HTML загруженной страницы не вставляется в карточку через `innerHTML`.



\## Ограничения



Страница из `src` должна быть доступна для чтения через `fetch`. Для чужого origin нужны CORS-заголовки на стороне сервера.



\## Локальная демонстрация



Запустите HTTP-сервер из корня проекта и откройте `demo/`:



```

python -m http.server 8000

```



Адрес: `http://localhost:8000/demo/`
